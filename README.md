# CityMatcher

**Find where you'd actually thrive.**

CityMatcher is an explainable relocation decision engine for European cities. You describe
what matters — budget, climate, safety, healthcare, work, walkability — and it ranks cities
with sourced data, an explicit trade-off and a realistic monthly budget.

The ranking is deterministic and versioned. AI is an optional interface layer for parsing
natural language; it never invents a city score. The app is fully usable without any API key.

**Live:** <https://city-matcher-sigma.vercel.app> · **Source:** <https://github.com/Joel-Revuelta/CityMatcher>

## What is in v1

- 42 European cities across 27 countries.
- A three-step preference wizard with a natural-language shortcut.
- Deterministic matching across 11 criteria, with hard filters and over-budget handling.
- Ranked results with strengths, trade-offs and monthly budget maths.
- A searchable city index with region and climate filters.
- Full city profiles: climate chart, cost breakdown, salary coverage, country context.
- Side-by-side comparison for 2–4 finalists.
- Anonymous shortlist in `localStorage`, plus shareable preference URLs.
- Methodology and per-city provenance pages.
- English UI, SEO metadata, JSON-LD, sitemap and accessible responsive design.
- A square, editorial “relocation ledger” design system documented in
  [`docs/DESIGN.md`](docs/DESIGN.md).

## Data pipeline

The committed dataset lives at `data/dataset.json`. It is generated from
`scripts/seed/cities.ts` plus two public APIs:

1. **Climate** — monthly high/low temperature, rainfall and sunshine normals from the
   Open-Meteo archive (2019–2024), aggregated in `scripts/build-dataset.ts`. Responses are
   cached in `scripts/.cache` (gitignored) so rebuilds are fast and polite.
2. **Country context** — latest available World Bank indicators for internet use, life
   expectancy, health spending, PM2.5, GDP PPP and unemployment.

Cost, salary and several livability values are a **curated model**, labelled medium
confidence in the UI. They are not presented as official statistics. Safety, walkability,
environment, happiness, public services and English are 0–100 composites; internet score is
derived from World Bank country data.

Run `pnpm data:build` to regenerate and `pnpm data:qa` to validate. The app never calls
an LLM to fill a missing metric.

## Optional AI parsing

Create `.env.local` from `.env.example` and set either:

```bash
GEMINI_API_KEY=...          # free tier; primary
GEMINI_MODEL=gemini-2.5-flash
GROQ_API_KEY=...            # free tier; fallback
GROQ_MODEL=llama-3.3-70b-versatile
```

The wizard's natural-language parser works without keys using deterministic rules. When a
key is present, the server route tries Gemini, then Groq, and falls back to rules on any error.
Only the preference text is sent; no account or personal data exists.

## Scoring in one paragraph

Hard filters remove cities outside your region, climate band, size and budget. Each remaining
city gets 0–100 scores for the criteria you kept; affordability, climate and work are computed
from your brief. The final match is the weighted average of only those criteria. A city up to
25% over budget can be shown when strict filtering leaves fewer than five results, but its
score is capped at 74 and clearly marked. Scores map to Excellent / Strong / Fair / Stretch.
The full formula and limitations are on `/methodology`.

## Deployment

The app is designed to run on the free Vercel Hobby tier:

1. Import the repository into Vercel.
2. Set `NEXT_PUBLIC_SITE_URL` to the deployment URL.
3. Deploy. No database or environment variables are required for core functionality.

Vercel Hobby is non-commercial; move to Cloudflare Workers or a paid plan before monetizing.

## Security

The original Angular hackathon build committed an OpenAI key. It has been removed from the
new app; keys are read server-side only. **The owner must still revoke the old key in the
OpenAI dashboard and purge it from git history.** The legacy build is preserved on the
`legacy/angular-v18` branch.
